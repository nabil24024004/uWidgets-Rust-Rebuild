## 3. Submission Options — Restricted Capabilities & Notes for Certification

### Restricted capabilities (`runFullTrust`)
**Question:** *"Why do you need the `runFullTrust` capability, and how will it be used in your product?\*"*

Copy and paste the exact justification below into the red-outlined **`runFullTrust`** box:

```text
uWidgets is a native Win32 desktop widget application written in pure Rust using Win32 windowing (CreateWindowExW), Direct2D, DirectWrite, and DirectComposition. It requires the runFullTrust capability for three core desktop integration functions that are only accessible to desktop full-trust processes:

1. Desktop-Layer Widget Window Management: uWidgets renders borderless, translucent widget cards pinned directly to the Windows desktop layer (HWND_BOTTOM / WS_EX_TOOLWINDOW / WS_EX_NOREDIRECTIONBITMAP) and registers a Win32 system tray notification icon (Shell_NotifyIconW) so users can manage their widgets without cluttering the taskbar.
2. Real-Time Liquid Glass Wallpaper Refraction: To render frosted glass and curved-bevel refraction over the user's desktop background, uWidgets reads the active desktop wallpaper path via SystemParametersInfoW(SPI_GETDESKWALLPAPER) and queries Windows DWM colorization/theme state (DwmGetColorizationColor / DwmSetWindowAttribute).
3. Local Hardware Telemetry for System Monitor Widgets: The built-in System Monitor widgets query read-only Windows performance APIs — PDH counters (PdhOpenQueryW) for CPU and Disk utilization, GlobalMemoryStatusEx for RAM usage, GetIfTable2 for network throughput, and GetSystemPowerStatus for battery status.

uWidgets does not require administrator privileges (runs as invoker), does not modify any system files or global settings, and stores all user widget configurations locally inside %LOCALAPPDATA%\uWidgets.
```

### Notes for certification *(Top box on Submission Options page)*

Copy and paste the testing instructions below into the **`Notes for certification`** box so Microsoft Store reviewers can verify the app immediately:

```text
Thank you for reviewing uWidgets v1.0.0!

HOW TO TEST THE APPLICATION:
1. Launch uWidgets: Upon launch, uWidgets immediately displays a default set of translucent Liquid Glass widgets (Clock, Date, Weather, and Calendar) on the right side of the desktop and adds the blue uWidgets icon to the Windows System Tray (Notification Area).
2. Open Settings & Widget Gallery:
   • Double-click the uWidgets icon in the Windows System Tray (or right-click the tray icon and select "Settings").
   • Alternatively, right-click any widget on the desktop and select "Settings".
3. Customize Appearance & Liquid Glass:
   • In Settings → Appearance, switch between Apple (Liquid Glass) and Windows (Fluent Acrylic) themes, choose Optical Presets (Crystal, iOS 26, Deep Frost, Prism), drag the live optical sliders (Blur Radius, Refraction, Bevel Width, Chromatic Dispersion, Specular Rim, Vibrancy, Frost Grain, Corner Radius), or pick a Glass Tint. All open widgets update in real time.
4. Customize Weather:
   • In Settings → Weather, click "Auto-Detect" to detect location via IP or type any city name in "Default City Search" and click "Search", or toggle between Celsius (°C) and Fahrenheit (°F).
5. Add, Move, Resize, or Remove Widgets:
   • In the left sidebar under "Widgets" (Calendar, Clock, Monitor, Notes, Reminders, Weather), click "+ Add Widget" on any of the 16 widget cards to spawn it on the desktop.
   • Drag any widget on the desktop to reposition it (snaps to an alignment grid).
   • Right-click any widget to change its Size (Small / Medium / Wide / Large), Edit content (Notes / Reminders / City), or Remove it.
6. Exit Cleanly:
   • Right-click the uWidgets System Tray icon and click "Exit".

NOTE ON ARCHITECTURE & PERMISSIONS:
• uWidgets is a standalone native x64 Rust binary using Win32 + Direct2D + DirectComposition. It requires no external runtimes, no user sign-in, and no administrator elevation.
```
